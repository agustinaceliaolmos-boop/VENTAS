# Análisis de Ventas de una Pequeña Empresa

## Integrante
- AGUSTINA OLMOS

## Escenario
Escenario B – Análisis de Ventas

## Descripción
Proyecto de análisis de datos de ventas utilizando Python, Visual Studio Code, GitHub Desktop y Jira.

## Dataset
Dataset de ventas simuladas en formato CSV.

## Ejecución
1. Clonar el repositorio.
2. Ejecutar el script `scripts/analisis_ventas.py` en Visual Studio Code.
3. Los resultados se generan en la carpeta `/resultados`.
